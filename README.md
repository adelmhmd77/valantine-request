VALANTINE REQUEST
=================
A static Valentine's Day proposal web page built with HTML, CSS and JavaScript.

Live Website : https://adelmhmd77.github.io/valantine-request/
Repository   : https://github.com/adelmhmd77/valantine-request
Author       : adelmhmd77


DESCRIPTION
-----------
"Will You Be My Valantine" is a single-page website that shows an animated
GIF, the question "Will You Be My Valantine", and two buttons: Yes and No.
It is hosted on GitHub Pages.


FEATURES
--------
* Animated GIF above the question
* Heading: "Will You Be My Valantine"
* "Yes" and "No" buttons (the "No" button has the id "no")
* Additional page: yes.html
* Responsive viewport setup
* No build step, no dependencies

Button behavior (what happens on click): Not specified.


TECHNOLOGIES
------------
* HTML5
* CSS3
* JavaScript
* GitHub Pages


SETUP
-----
1. Clone the repository:
       git clone https://github.com/adelmhmd77/valantine-request.git
2. Open the folder:
       cd valantine-request
3. Open index.html in any modern web browser.


USAGE
-----
Open the live website (or index.html locally), read the question,
and click "Yes" or "No".
